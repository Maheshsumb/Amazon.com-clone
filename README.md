# Amazon Homepage Clone 🚀

This project is a clone of the Amazon homepage, designed purely on the frontend. It aims to replicate the look and feel of the Amazon homepage using HTML, CSS, and maybe some JavaScript for interactivity.

## Project Overview ℹ️

The goal of this project is to showcase my frontend development skills by recreating the layout, design, and functionality of the Amazon homepage. This includes:

- Replicating the header with navigation links, search bar, and user account options.
- Displaying various product categories and featured products.
- Designing a footer with relevant links and information.

## Technologies Used 💻
- HTML5 ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white) : For structuring the webpage.
- CSS3 ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white) :For styling and layout.
  
## Project Structure 📁

The project structure is organized as follows:

- `index.html`: Main HTML file containing the structure of the Amazon homepage.
- `styles/`: Directory containing CSS files for styling.
  - `styles.css`: Main stylesheet for the project.
  -  `utils.css`: Commonly used CSS stylesheet for the project.

## Getting Started 🚦

1. Clone the repository: `git clone https://github.com/Maheshsumb/Amazon.com-clone.git`
2. Open `index.html` in your web browser to view the Amazon homepage clone.
3. Customize and modify the code as needed to suit your requirements.
